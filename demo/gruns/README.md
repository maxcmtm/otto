# Grüns: end-to-end test run (2026-09-29)

Otto was given one URL, gruns.co, and ran the whole pipeline: scan, brand profile, strategy, compliance rules,
competitor and Ad Library research, the October content plan (66 posts), copy, rendered cards, a launch reel,
six ad angles with creatives, and the October paid plan. Grüns is not a client; only public data was used.

- `page/`: the review page (open `page/index.html`), with web-sized renders and the reel.
- `brand/`: the brand files Otto wrote (profile, strategy, compliance, competitors, angles with ad copy, keywords,
  the October copy with render specs, research notes, logo). Useful as a fixture for a supplement / Shopify client.

Full-resolution renders (`posts/`, `ads/`, `gruns-reel.mp4`) stay local and are git-ignored.
The engine fixes this run produced are listed on the page under "Found and fixed during this run".
